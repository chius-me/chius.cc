## 首言
随着开发平台逐渐往 HomeLab 的设备上迁移、以及 AI Agent 在类 Unix 系统上的支持更好，我对 Windows 的需求也越来越少，因此我下定决心要将日常移动办公的业务迁移到 Macbook，然后开发都在 HomeLab 服务器上。  
但这台 天选4 Windows 笔记本经过我长达3年的调教，还算是好用了，在彻底下放她之前，我来分享一下我的 Windows 好用软件清单。
## 软件清单
### [Chrome](https://www.google.com/chrome/)
在倒向 Chrome 之前，我一直是个 Edge 的用户，系统安装后直接打开就能用，国内直连的 Bing 搜索引擎、简洁的设计，在过去很长一段时间，Edge 在国内还算好用。  
但 Edge 的每一次更新都如同狗屎一样，越来越多的广告，超多广告的 Bing 搜索引擎。和那些360、2345、QQ 浏览器没什么两样了，所以 Chrome 就成了我的首选，Material Design 的 UI 设计也还算好看。  
至于 Firefox，我目前也在用，但还是因为浏览器内核，经常会遇到一些 WEB 兼容性问题。
![Chrome](https://s3.chius.cc/2026-06-09-windows-software-chrome.png)
### [Bun](https://bun.com/)
Bun 是一个 JavaScript 的 runtime，因为 Node.js 在 Windows 上用 nvm 管理，除了用 WSL2，就只能用 Chocolatey 包管理器安装，所以想要在 Windows 端享用 JavaScript 的庞大生态，我选择原生支持Windows 的 Bun 来替代 Node.js。
> Node.js 应该还有其他方式在 Windows 上安装，比如 Scoop 包管理器，但我没有尝试过，[Node.js 官网](https://nodejs.org/zh-cn/download) 也没有提供这个方式。
### [Scoop](https://scoop.sh/)
Scoop 是 Windows 上的一个包管理器，类似于 Ubuntu/Debian 上的 apt 或者 Macos 上的 Homebrew，可以方便地安装和管理各种软件。
### [Visual Studio Code](https://code.visualstudio.com)
Visual Studio Code 是一款具备丰富插件生态的编辑器，和 Jetbrains IDE 系列不同的是，VS Code 本体只是一个编辑器，需要搭配一些插件才能达到某款 Jetbrains IDE 的功能，但也因此，其性能更好，更轻量。
> 但如今 2026年的年中，VS Code 的一次次更新，让其越来越像 Cursor 了，还内置一个像 Codex 的助手，在右上角可以打开，也可以右键完全隐藏掉。  

![VS Code](https://s3.chius.cc/2026-06-09-windows-software-vscode.png)
> 因为患有散光，用暗色主题的时候，黑底白字的情况下，那些白字会有一圈光晕，很不舒服，所以我一直用着 Solarized Light 主题。
### [Windows Terminal](https://aka.ms/terminal)
Windows Terminal 是微软官方推出的一个终端应用，我选用这个的最大原因还是这个更好看一点，之前用过Termius、Xshell、MobaXterm等等，感觉都很丑，直接在 Windows Terminal 里打开powershell，然后 ssh 到服务器就 OK 了。
